# Итеративный интерпретатор кода стековой машины Lama

Данный форк репозитория Lama создан, чтобы поддержать возможность использовать **итеративный интерпретатор** для интерпретации байткода стековой машины Lama.

Данный md файл создан с целью описать подготовительную работу, а также полученные артефакты работы

## Структура репозитория

- bench - Pretty print библиотека

Пишут, что его можно подсобрать, но никаких рецептов сборки не увидел, dune b bench тоже не подхватил

- byterun - Дизассемблер 

Разбирает секции .bc файла, а затем декодирует инструкции и offset, операнды в Lama передаются после инструкции
